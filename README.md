# Health Buddy

saya ingin membuat Aplikasi Health Tracker. pada bagian ondoarding ada pilihan masuk/daftar dengan google dan "Install'. Tombol instal ini untuk install sebagai PWA. Pada menu home dalam create "Group". Pada group bisa invite anggota lain untuk berbagi "Rekam Kesehatan". Selain Tombol Home ada menu Rekam dan Profile. Rekam menampilkan data kesehatan seperti track Tidur, Langkah, dan Detak Jantung. Data pada menu Rekam berasal dari data Health Connect yang ada di HP. Tampilannya seperti referensi. tampilan untuk HP dengan navbar dan header bar yang selalu tampil setelah masuk ke aplikasi.
